## CoreBound Quality
This datapack adds quality tiers to vanilla Minecraft items.

Quality items can have different stats, durability, names, lore and custom item_models.

## Loot
Quality items can be added to vanilla loot tables.

For example, the village toolsmith loot table can add Uncommon and Rare versions of items already found in the base loot table.

The original items are still available.

## How It Works
Quality items are stored as item modifiers and can be referenced by loot tables and recipes.

An inventory-change advancement runs a function which checks the player's inventory for quality items. The function identifies the quality variant using the item's item_model and applies the corresponding item modifier.

This handles the quality-specific stats and item properties.

## Compatibility
Designed for Minecraft 26.2

Requires the CoreBound Resource Pack for the custom item models.

The datapack uses vanilla Minecraft datapack functionality and does not require mods.
